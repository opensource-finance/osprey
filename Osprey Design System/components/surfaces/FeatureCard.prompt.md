Marketing feature tile with a circular icon chip, title, and description. Reveals a border and scales its icon on hover.

```jsx
<FeatureCard
  icon={<i data-lucide="box"></i>}
  title="Single Binary"
>
  Compiled Go. No JVM. No node_modules. Just one standard binary that runs anywhere.
</FeatureCard>
```

Use in a 2-col grid (`max-w-5xl`, 32px gap) per the source layout. Icons should be Lucide/Feather line icons at 24px.
