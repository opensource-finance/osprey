Brand wordmark lockups.

```jsx
<Wordmark brand="osf" />                 {/* red square + opensource.finance */}
<Wordmark brand="osf" dot="circle" />    {/* header variant */}
<Wordmark brand="osprey" size={20} />    {/* glyph + OSPREY */}
```

The red square is the canonical dot motif (matches the OG lockup). On dark surfaces, pass `color="#fff"`.
